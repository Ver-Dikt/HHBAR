# RestoPlace в HHBAR

Страница `booking.html` использует официальный виджет RestoPlace и сохраняет существующую схему зала HHBAR.

## Текущий режим

- Скрипт виджета подключён с выданным HHBAR хэшем.
- Нажатие на доступный стол открывает общий виджет RestoPlace.
- Кнопки «Забронировать онлайн» используют официальный класс `restoplace-click-open`.
- Собственная плавающая кнопка сервиса скрыта, чтобы не менять дизайн сайта.
- API, webhooks и платные интеграции не используются.

## Привязка конкретных столов

RestoPlace официально поддерживает ссылку `?open_item=ID`, где `ID` — «id объекта» из редактора столов. Чтобы включить точную привязку:

1. В RestoPlace откройте книгу резервов → «Редактор столов».
2. ID столов HHBAR уже заполнены: столы 1–20 соответствуют `830804`–`830823`, VIP — `830890`.
3. В `src/scripts/restoplace.js` осталось заполнить `widgetUrl` ссылкой вида `https://ИМЯ.restoplace.ws/`.

После добавления `widgetUrl` выбранный стол будет открываться официальной ссылкой с `open_item`; пока ссылки нет, автоматически используется общий виджет.
