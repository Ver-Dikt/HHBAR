# RestoPlace в HHBAR

Страница `booking.html` использует официальный виджет RestoPlace и сохраняет существующую схему зала HHBAR.

## Текущий режим

- Скрипт виджета подключён с выданным HHBAR хэшем через `app.restoplace.cc`.
- Нажатие на доступный стол открывает общий виджет RestoPlace.
- Кнопки «Забронировать онлайн» используют официальный класс `restoplace-click-open`.
- Собственная плавающая кнопка сервиса скрыта, чтобы не менять дизайн сайта.
- API, webhooks и платные интеграции не используются.

## Привязка конкретных столов

RestoPlace поддерживает параметр `?open_item=ID`, где `ID` — «id объекта» из редактора столов. Персональный загрузчик HHBAR переносит GET-параметры страницы внутрь своего iframe, поэтому дополнительная публичная ссылка не требуется.

ID столов HHBAR заполнены: столы 1–20 соответствуют `830804`–`830823`, VIP — `830890`.

При выборе стола код временно добавляет `open_item` и количество гостей в адрес страницы, вызывает официальный загрузчик, а затем сразу восстанавливает исходный адрес. Внутри RestoPlace открывается форма нужного объекта.
