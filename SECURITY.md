# Безопасность HHBAR

Сайт не содержит серверной авторизации, форм оплаты или базы броней. Статус столика считается неподтверждённым до звонка администратору.

Файл `_headers` применяется на Netlify и совместимых платформах. На другом хостинге перенесите эти заголовки в конфигурацию CDN или веб-сервера. Без серверных HTTP-заголовков браузер не применит CSP, HSTS и защиту от MIME-sniffing.

Доступ к публикации должен быть защищён двухфакторной аутентификацией. Не помещайте токены, пароли, ключи Telegram-ботов или API в HTML, JavaScript и Git.

Афиша читается из `src/data/events.json`; прошедшие даты автоматически уходят в архив. Используйте только локальные изображения внутри `img/events/`. Цены и состав меню проверяйте перед каждой публикацией.
